# ADR-0001: Locked MVP Scope

Date: 2026-09-01
Status: Accepted

## Context

IdleCUA is a local Python app that runs a policy-gated computer-use agent during idle periods on the owner's Mac. Need to lock scope to avoid unbounded expansion.

## Decision

MVP includes:
- Installable package (uv, src-layout, Typer+Rish CLI thin over public Application API)
- Onboarding interview with confirmed profile gate
- PolicyEngine (allowlist, deny-zones, action classes)
- ComputerDriver contract (fake for tests, real Cua later) + ModelProvider OpenAI-compatible
- IdleDetector (Quartz HID), scheduler, limits, emergency stop
- Execution loop with SQLite memory, history, Markdown report
- Browser on main Chrome profile (read-only first)
- Anti-repeat 7-day dedupe

Out of scope for MVP: ChatGPT browser login, local HTTP/MCP server, GUI/Electron, global hotkey, Lume VM, second driver, additional providers, embeddings/vector DB, plugin marketplace, DI/event-sourcing, multi-user/cloud.

## Consequences

Keeps single package, minimal contracts, focused tests on acceptance criteria. Manual checklist covers non-automatable verifications.
